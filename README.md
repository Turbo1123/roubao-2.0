# 肉包 Roubao 2.0 for iPhone 已迁入原仓库

**正式项目地址：[Turbo1123/roubao](https://github.com/Turbo1123/roubao)。**

按作者的项目组织方式，iPhone 2.0 与旧安卓版现在放在同一个仓库：

- [iPhone 2.0 源码](https://github.com/Turbo1123/roubao/tree/main/ios)
- [中文 README](https://github.com/Turbo1123/roubao/blob/main/README.md)
- [English README](https://github.com/Turbo1123/roubao/blob/main/README_EN.md)
- [详细安装教程](https://github.com/Turbo1123/roubao/blob/main/ios/docs/INSTALL.md)
- [旧版 Android 文档](https://github.com/Turbo1123/roubao/blob/main/docs/ANDROID.md)

运行时无需 Wi-Fi、越狱、电脑或额外控制硬件；首次仍需 Mac + USB 配置。不需要 WDA。Android 暂未随 iPhone 2.0 更新。

本仓库保留最初的 iPhone 源码快照和 AGPL-3.0 许可，供历史参考。后续请在原仓库查看文档、提交 Issue 和获取更新。
